# Elemental Defenders — Tower Defense (HTML5)

เกม Tower Defense แฟนตาซี เล่นบนเบราว์เซอร์ (ออกแบบสำหรับ iPad แนวนอน รองรับเมาส์/ทัช) ไม่มี build step — เป็นไฟล์ static ล้วน

## Deploy บน Vercel
1. แตกไฟล์ zip นี้ แล้วอัปโฟลเดอร์ขึ้น GitHub (หรือใช้ `npx vercel` ในโฟลเดอร์นี้)
2. ใน Vercel: New Project → เลือก repo → Framework Preset = **Other** → Build Command เว้นว่าง → Output Directory = `.` (root)
3. Deploy เสร็จเปิดลิงก์เล่นได้ทันที
ทดสอบในเครื่อง: `python3 -m http.server` แล้วเปิด http://localhost:8000 (ต้องเปิดผ่านเซิร์ฟเวอร์ ไม่ใช่ดับเบิลคลิกไฟล์)

## เซฟเกม
เซฟอัตโนมัติใน localStorage ของเบราว์เซอร์ผู้เล่นแต่ละคน → ไม่ต้องใช้รหัส คนอื่นที่เปิดเว็บเดียวกันมองไม่เห็นเซฟของเรา
(บันทึกทุกครั้งที่สร้าง/ผสม/ขายหอระหว่างเวฟ, จบเวฟ และกด "บันทึกและออก")

## โหมดเวฟ
เลือกได้ก่อนเริ่มด่าน: 50 / 100 / 200 / ∞ — เวฟถูกเจนสดเมื่อเล่นถึง มินิบอสทุก 10 เวฟ บอสใหญ่ทุก 25 เวฟ (เวฟ 100+ มาเป็นฝูงบอส) โหมด ∞ ไม่จำกัดเวลา ได้ดาวตามจำนวนเวฟที่รอด (50/100/200)

## ระบบสมบัติ
ลังเสบียง/หีบสมบัติ/ผลึกธาตุ/เห็ดเยียวยา/น้ำพุมนตรา วางอยู่ใกล้ทางเดิน หอในระยะจะยิงเองเมื่อไม่มีมอนสเตอร์ หรือแตะแล้วกด 🎯 เพื่อสั่งยิงทันที แตกแล้วได้รางวัลและช่องนั้นสร้างหอได้ เกิดใหม่ทุก 10 เวฟ

## ปรับสมดุล
ค่าตัวเลขทั้งหมดอยู่ที่ `js/core.js` → `ED.CONFIG` (ตัวคูณธาตุ 2.0/0.4/1.0, ราคาหอ, เงื่อนไขผสม, การโตของ HP/ทอง ฯลฯ)

## โครงสร้าง
| ไฟล์ | หน้าที่ |
|---|---|
| js/core.js | CONFIG, วงจรธาตุ, ตาราง Elemental Interaction ครบ 36 คู่ |
| js/towers.js | องค์ประกอบธาตุ → ค่าพลัง รูปแบบโจมตี สกิล 21 ตระกูล, เงื่อนไขผสม (13,096 รูปแบบ) |
| js/monsters.js | สร้างสายพันธุ์มอนสเตอร์ (4,680 สายพันธุ์ + ชิ้นส่วนตกแต่ง), ค่าพลัง, เวฟ |
| js/mapgen.js | เจนแผนที่ใหม่ทุกด่านจากชิ้นส่วนทางเดิน/ของตกแต่ง/พื้นหลัง 9 ไบโอม |
| js/sprites.js | ประกอบหอ/มอนสเตอร์จากชิ้นส่วนภาพ, วาดแผนที่ |
| js/fx.js | เอฟเฟกต์อนุภาค ลำแสง สายฟ้า วงคลื่น ตัวเลขดาเมจ |
| js/game.js | ระบบต่อสู้ สถานะ สกิล เวฟ เวลา เลือดปราสาท ดาว |
| js/ui.js | หน้าจอ, HUD, สร้าง/ผสม (แตะ+ลาก), สมุดบันทึก, ตั้งค่า |
| js/music.js | เพลงประกอบแบบเจนเนอเรตสด: สุ่มคีย์/ทางคอร์ด/ทำนอง/การเรียบเรียงทุก 8 บาร์ ไม่ซ้ำเดิม (title / battle / boss + เพลงชนะ/แพ้) |
| js/audio.js | เสียงเอฟเฟกต์สังเคราะห์พร้อม reverb (ไม่มีไฟล์เสียง) |
| assets/ | atlas ชิ้นส่วนที่ทำความสะอาดแล้ว, พื้นหลังแผนที่ 30 แบบ, ภาพหน้าเริ่มเกม/ปุ่ม |
